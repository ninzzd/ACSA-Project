# ACSA-Project
Hardware implementation and optimization of MiKV (multi-tiered KV caching) for faster/high-throughput LLM inference

## Setup
Create Python Virtual Environment:
```bash
python3 -m venv .venv
```
Activate the venv:
```bash
source .venv/bin/activate
```
Install dependencies:

```python
pip3 install -r requirements.txt
```
